# ML Collections

This repository, **ml-collections**, contains Jupyter notebooks, code snippets, datasets, and projects created during my **CS20L** (Machine Learning Laboratory) and **Emerging Technologies** subjects. It is organized to support coursework, hands-on labs, and project-based learning in machine learning and data science.

## Directory Structure

- [**cs20L/**](./cs20L/)
  - [**datasets/**](./cs20L/datasets/)  
    Contains a variety of CSV datasets for machine learning tasks, including sentiment analysis, classification, regression, and more. Example files:
    - `sentiment-dataset.csv`
    - `IRIS2.csv`
    - `Salary_Data.csv`
    - `Social_Network_Ads.csv`
    - ...and others
  - [**Lab Activities/**](./cs20L/Lab%20Activities/)  
    Contains guided lab activities for practical ML exercises.
  - [**Lab Exercises/**](./cs20L/Lab%20Exercises/)  
    Contains additional exercises for practice and assessment.
  - [**lab_exams/**](./cs20L/lab_exams/)  
    Contains exam materials for lab-based assessments.
  - [**Project Proposal/**](./cs20L/Project%20Proposal/)  
    Contains templates and examples for proposing ML projects.
  - [**Sample Codes/**](./cs20L/Sample%20Codes/)  
    Contains example code snippets and scripts for various ML algorithms and data processing tasks.
  - [**sentimen-analysis/**](./cs20L/sentimen-analysis/)  
    Contains sentiment analysis datasets and related scripts.

- [**emerging-tech/**](./emerging-tech/)
  - [**AppointmentModel.ipynb**](./emerging-tech/AppointmentModel.ipynb)  
    Jupyter notebook for appointment prediction/classification.
  - [**Priority_Classifier.ipynb**](./emerging-tech/Priority_Classifier.ipynb)  
    Jupyter notebook for classifying priorities.
  - [**datasets/**](./emerging-tech/datasets/)  
    Additional datasets for emerging technology projects.

## Usage

1. **Datasets:**  
   Use the datasets in [`cs20L/datasets/`](./cs20L/datasets/) and [`emerging-tech/datasets/`](./emerging-tech/datasets/) for your ML experiments, model training, and data analysis.

2. **Sample Codes:**  
   Refer to the sample codes for examples of data preprocessing, model building, evaluation, and visualization.

3. **Lab Activities & Exercises:**  
   Follow the activities and exercises to reinforce your understanding of ML concepts and techniques.

4. **Projects:**  
   Explore the project proposals and Jupyter notebooks for end-to-end ML project examples.
